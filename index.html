ticktessly's Termux Repository

Custom APT repository for Termux with packages not available in the official repos.

Quick install

curl -sL https://ticktessly.github.io/termux-repo/install.sh | bash

This adds the repository to $PREFIX/etc/apt/sources.list.d/ and runs pkg update.

Manual install

  1. Add the repository source

    Create $PREFIX/etc/apt/sources.list.d/ticktessly-repo.list containing:

    deb [trusted=yes] https://ticktessly.github.io/termux-repo stable main

  2. Refresh the package lists

    pkg update -y

  3. Install a package

    pkg install opencode
